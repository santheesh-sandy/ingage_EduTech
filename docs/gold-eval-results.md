## ✔ learn-concept subnet (learner)

> **User:** Explain subnetting with an example.
**Bot:** Subnetting is the process of splitting a single, large network into smaller, more manageable sub-networks (subnets). It helps reduce network congestion and improves security.  
  
The **subnet mask** determines which part of an IP address represents the network and which part represents individual host devices.  
  
**Concrete Example:**  
Imagine your office has the network address `192.168.1.0/24`. The `/24` (or `255.255.255.0`) means the first 24 bits are for the network, leaving 8 bits for hosts (up to 254 usable devices).  
  
If you want to split this into two separate departments (e.g., Sales and HR), you borrow 1 bit from the host portion, changing the mask to `/25` (`255.255.255.128`):  
- **Subnet 1:** `192.168.1.0/25` (Usable IP range: `192.168.1.1` to `192.168.1.126`)  
- **Subnet 2:** `192.168.1.128/25` (Usable IP range: `192.168.1.129` to `192.168.1.254`)  
  
Devices in Subnet 1 cannot communicate directly with Subnet 2 without going through a router.  
  
This topic and practical IP planning are covered in **Module 1: Networking fundamentals and addressing** of your IT Network System Administrator course.

## ✔ learn-two tries mentor (learner)

> **User:** What is OSPF?
**Bot:** OSPF (Open Shortest Path First) is a dynamic routing protocol used by routers to automatically find and share the best paths for sending network traffic.   
  
It is a **link-state protocol** that uses bandwidth to calculate cost and runs the Dijkstra algorithm to determine the shortest and fastest route. Whenever there is a change in the network—like a broken connection—OSPF quickly adapts and updates the routing paths across the network.   
  
**Example:** If Router A has two ways to reach Router B—a high-speed fibre link and a slow backup link—OSPF calculates that the fibre link has a lower cost and automatically directs traffic through it. If that fibre link fails, OSPF immediately switches traffic to the backup path.  
  
This concept is covered in **Module 2: Network devices and routing in Packet Tracer**.
