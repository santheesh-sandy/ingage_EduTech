## ✔ learn-concept subnet (learner)

> **User:** Explain subnetting with an example.
**Bot:** Subnetting is the process of splitting a single large network into smaller, manageable sub-networks (subnets) to improve performance and security.   
  
The **subnet mask** indicates which part of an IP address represents the network and which part identifies the specific host/device.  
  
**Concrete Example:**  
Imagine an office assigned the network address `192.168.1.0/24` with the default subnet mask `255.255.255.0`. This gives one network with up to 254 usable devices.  
  
If you need two separate departments (like Sales and Accounts), you can borrow 1 bit from the host portion, changing the mask to `/25` (`255.255.255.128`):  
- **Subnet 1:** `192.168.1.0/25` (Usable IP range: `192.168.1.1` to `192.168.1.126`)  
- **Subnet 2:** `192.168.1.128/25` (Usable IP range: `192.168.1.129` to `192.168.1.254`)  
  
Now each department has its own isolated broadcast domain.  
  
This is covered in detail in **Module 1: Networking fundamentals and addressing** of your IT Network System Administrator course in My Learning.

## ✔ learn-two tries mentor (learner)

> **User:** What is OSPF?
**Bot:** **OSPF (Open Shortest Path First)** is a dynamic, link-state routing protocol used by routers to automatically learn and share network routes.   
  
Instead of manually configuring every path, OSPF-enabled routers map the entire network topology and use Dijkstra’s algorithm to calculate the shortest, fastest path to each destination based on cost (bandwidth). Because it recalculates quickly when a link goes down, it offers fast convergence and scales well in large networks by organising them into areas.  
  
**Example:**  
Imagine two paths between Office A and Office B. Path 1 is a slow 10 Mbps backup line, while Path 2 is a high-speed 1 Gbps fiber link. OSPF automatically assigns a lower cost to Path 2 and sends traffic through it. If Path 2 gets cut, OSPF instantly detects the break and redirects traffic over Path 1.  
  
You will cover OSPF, dynamic routing, and configure routing in **Module 2: Network devices and routing in Packet Tracer**.
